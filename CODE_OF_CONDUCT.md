# Code of Conduct

## Our Standards

We are committed to providing a welcoming, respectful, and constructive environment for everyone who participates in the ai-terminal-chat project.

Examples of behavior that contribute to a positive environment include:

- Being respectful and considerate of others.
- Giving constructive feedback.
- Accepting different perspectives and experiences.
- Focusing on what is best for the project and its users.
- Being especially mindful of accessibility and inclusive design.
- Respecting contributors who use AI-assisted development tools.

Unacceptable behavior includes:

- Harassment, discrimination, intimidation, or personal attacks.
- Trolling, insulting, or deliberately disruptive behavior.
- Publishing someone else's private information without permission.
- Deliberate disruption of project discussions, issues, or pull requests.
- Any other conduct that would reasonably be considered inappropriate in a professional or open-source community.

## Accessibility

Accessibility is an important part of this project. Contributors should make a reasonable effort to ensure that changes do not unnecessarily introduce barriers for people using screen readers, keyboard navigation, or other assistive technologies.

Accessibility concerns can be reported through the project's issue tracker.

## Project Discussions

Please keep discussions focused on the project and its users. Technical disagreements are welcome, but they should remain constructive and respectful.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, pull requests, or other contributions that violate this Code of Conduct.

Repeated or serious violations may result in temporary or permanent restriction from participating in the project.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the project maintainers rather than starting a public discussion.

For security vulnerabilities, please follow the project's security reporting instructions rather than publicly disclosing the vulnerability.

## Scope

This Code of Conduct applies to project spaces and activities, including:

- GitHub issues and discussions.
- Pull requests.
- Code reviews.
- Project documentation.
- Other official project communication channels.

It also applies when an individual is representing the project in public spaces.

## Attribution

This Code of Conduct is adapted for the ai-terminal-chat project from common open-source community standards, including the Contributor Covenant.
