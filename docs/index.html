AI Terminal Chat

Accessible AI chat for local projects, with controlled tools and support for local AI.

DownloadsView source

Built for local projects

AI Terminal Chat connects an AI assistant with project files and controlled tools while keeping the application useful for desktop development workflows.

Accessibility first

The project is designed with keyboard and screen-reader users in mind, with ongoing accessibility testing and improvements.

Flexible AI

Use supported remote providers or local AI backends such as Ollama, depending on your setup and privacy needs.

AI Terminal Chat is open source under the Apache License 2.0.
